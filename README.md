# brainstorm

> **if you want to be normal, use any skill.**
> **if you want to change anything, use brainstorm.**

一個讓 AI 跳脫「最典型答案」、和你一起激發創意的 Claude skill。

AI 預設會往最可能、最安全的答案收斂。`brainstorm` 用「變異 + 篩選」的方式，把它推離平均值，再用評分和實驗把真正有價值的點子留下來。

## 流程

```
1. 定義：問題 + 限制 + 「什麼叫好」（評分標準）
2. 發散：先禁用 5 個直覺解，再產生 10+ 個點子（跨領域、改限制、反轉、強制分散）
3. 組合：交叉合併、推到極端
4. 收斂：先 steelman 再紅隊攻擊，用評分標準挑出 2–3 個
5. 驗證：寫評分腳本、做最小原型、記錄失敗原因
6. 迭代：把失敗原因當成新的限制條件，回到第 2 步
```

整個 session 會維護一份 `idea-log.md`，記錄點子、新穎度與可行性分數、禁用的直覺解，以及失敗原因。

## 特點

- **不附和**：對你的想法先講出最強版本，再指出最脆弱的地方
- **避免錨定**：建議你先別說自己的想法，等 AI 發想完再比較
- **保留失敗**：被否決的點子會連同原因留下，當作下一輪的材料
- **可平行**：彼此獨立的方向可以交給多個 subagent 同時發想，避免互相影響

## 安裝

把 `brainstorm/` 資料夾放進你的 skills 目錄，例如 Claude Code 的：

```
~/.claude/skills/brainstorm/SKILL.md
```

或在 Claude 的設定中上傳這個 skill。

## 使用

```
/brainstorm 我想讓產線測試時間縮短 30%，但不能增加設備
```

也可以直接說「幫我發想……」「腦力激盪一下……」。
